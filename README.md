# SV Bedum scorebord

## Bekende beperkingen & Opmerkingen
- **Wedstrijdopslag:** Wedstrijden worden nog steeds opgeslagen in de lokale database (`wedstrijden.json`).
- **Sponsorbeheer:** Het is momenteel niet mogelijk om sponsoren handmatig te verwijderen via de interface.
- **Sponsor Synchronisatie:** Bij het opnieuw synchroniseren van sponsoren wordt de huidige map niet eerst leeggemaakt; nieuwe sponsoren worden toegevoegd of overschreven.
